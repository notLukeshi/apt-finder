# Code of Conduct

## Our pledge

We are committed to making participation in APT-Finder a harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive
- Focus on the code and the problem
- Share feedback clearly and politely
- Respect privacy, data ownership, and local laws

## Unacceptable behavior

- Harassment, discrimination, or personal attacks
- Publishing secrets, private data, or unauthorized scrape outputs
- Deliberately breaking functionality for other contributors
- Spam, trolling, or disruptive behavior

## Enforcement

Project maintainers may remove, hide, or reject contributions that violate this code of conduct.
