# Scraping Ethics and Data Use

APT-Finder is designed for personal apartment research, not for circumventing site policies.

## Guidelines

- Respect each website's terms of service and robots guidance.
- Keep request rates conservative.
- Use a clear user-agent and avoid abusive concurrency.
- Do not publish private listings, raw HTML captures, or personal address data unless you are certain it is allowed.
- Keep your API keys, OTP assets, and local configuration off GitHub.

## Public release note

The repository is open-source, but the user is responsible for how they operate the scrapers and what data they collect.
